# §1.2.3. Типы и скорости волн

`calculate_wave_speeds(left, right, gamma, star)` из `wave_speeds.hpp` возвращает два `WaveInfo`. Если `p_star > p_K`, волна с соответствующей стороны ударная: используется `speed` по (15.21) или её правому аналогу из §15.9. Иначе это волна разрежения: `head_speed` и `tail_speed` по §15.9.

Для ударной волны поля `head_speed` и `tail_speed` не используются; для разрежения не используется `speed`. Это удобно для дальнейшей программы построения диаграммы `x–t`. Типы и скорости печатает `main.cpp` при запуске `./build/prac15 config.yaml`.
