# §1.2.6. Проверка возникновения вакуума

`check_vacuum(left, right, gamma)` из `vacuum.hpp` вычисляет разность скоростей `u_right - u_left` и порог `2*(a_left + a_right)/(gamma - 1)` из условия (15.15). При равенстве или превышении порога положительного корня для `p_star` нет: образуется область вакуума.

`solve_riemann(left, right, gamma)` из `exact_riemann_solver.hpp` проверяет условие **до** метода Ньютона. Возвращает `RiemannResult`: поле `vacuum` содержит результат проверки, а `solution` содержит `PressureResult`, `StarState` и `WavePair` только если вакуума нет. Решатель не обращается к сетке, `config.yaml`, файлам или графикам. Отбор `sample_solution` остаётся отдельной функцией.

При вакууме программа печатает понятное сообщение и заканчивает работу штатно, без `NaN` и аварийного завершения. Само решение с вакуумом по заданию строить не требуется. Для проверки можно скопировать `config.yaml`, задать `initial.left.u: -10.0` и `initial.right.u: 10.0` (сохранив прочие параметры), затем запустить `./build/prac15 путь_к_копии.yaml`.
