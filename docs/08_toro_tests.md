# §1.3. Пять тестов Торо

Пять наборов начальных данных из таблицы задания хранятся в `examples/toro_1.yaml` … `examples/toro_5.yaml`. Каждый файл имеет тот же формат, что и `config.yaml`; в нём указаны обе стороны разрыва, `gamma = 1.4`, область `[0, 1]`, `x0 = 0.5` и нужный момент `t_out`. Табличные значения `p*`, `u*`, двух плотностей и ожидаемые типы волн находятся в `src/toro_cases.cpp`. Это данные из `docs/prac15.pdf`, а не новая теория.

## Запуск одной командой

После сборки проекта выполните:

```bash
ctest --test-dir build --output-on-failure
```

CTest запускает `toro_tests`; эта программа проходит все пять наборов и сообщает `[PASS]` или `[FAIL]` для каждого. Ненулевой код выхода означает, что хотя бы один тест не прошёл. Для печати подробных строк без CTest можно вызвать `./build/toro_tests` из корня проекта.

## Таблицы для отчёта

Команда `./build/toro_tests docs/toro_results.md` записывает пять таблиц: рассчитанное и табличное значения `p*`, `u*`, `rho*L`, `rho*R`, относительное отклонение каждой ненулевой величины, типы и скорости волн, выбранную формулу GUESSP и число итераций Ньютона. Для табличного нуля вместо относительного отклонения приводится абсолютная ошибка. Полученный файл можно использовать при подготовке итогового PDF-отчёта.

Эталонные числа в PDF округлены, особенно `p* = 0.00189` в тесте 2. Поэтому проверка допускает относительное отклонение не более `0.5%` **или** абсолютное не более `1e-5`. Для нулевого эталона применяется только абсолютный допуск; отдельная регрессионная проверка отклоняет значение `1` при эталоне `0`. Проверяются также типы волн, конечность и порядок их скоростей, а для состояния при `S = 0` — положительность плотности и давления. Эти дополнительные проверки не подменяют сравнение с таблицей.

## Состав тестов

1. Задача Сода: левая волна разрежения, правая ударная волна.
2. Разлёт двух одинаковых газов: две волны разрежения.
3. Левая половина задачи Вудворда — Колеллы: разрежение слева, ударная волна справа.
4. Правая половина той же задачи: ударная волна слева, разрежение справа.
5. Столкновение двух сильных ударных волн.

Формулы для давления, плотностей и скоростей взяты из §15.5–§15.9 лекций. Сами тестовые состояния, моменты времени и эталонные значения взяты из задания.
