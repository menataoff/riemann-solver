# §1.1. Постановка и `config.yaml`

Программа читает один файл конфигурации. По умолчанию это `config.yaml` в текущем каталоге; другой путь можно передать первым аргументом: `./build/prac15 my_case.yaml`.

В `initial.left` и `initial.right` задаются постоянные начальные состояния слева и справа от `domain.discontinuity`: `rho` — плотность, `u` — скорость, `p` — давление. По §15.2 скорость звука равна `sqrt(gamma * p / rho)`, удельная внутренняя энергия — `p / ((gamma - 1) * rho)`. `gas.gamma` — показатель адиабаты. Плотность и давление должны быть положительными, `gamma` — больше единицы.

`domain.x_min` и `domain.x_max` задают отрезок для будущего отбора и графиков. `domain.discontinuity` — положение исходного разрыва внутри него. Для отбора в `output.sample_x` в момент `output.sample_time` используется луч `S = (sample_x - discontinuity) / sample_time` (§15.9). В схеме Годунова для неподвижной грани нужен `S = 0`.

`method.solver: exact` выбирает точный решатель. `method.scheme: none` показывает, что в части 1 схема на сетке не запускается. Другие имена пока отклоняются с сообщением об ошибке; в будущем здесь можно будет выбрать HLL, HLLC или схему Годунова без изменения точного решателя.

`boundary.left` и `boundary.right` — граничные условия будущего расчёта на сетке. Тип `transmissive` означает копирование внутреннего состояния в фиктивную ячейку; тип `fixed` означает заданные `rho`, `u`, `p` в блоке соответствующей границы. Текущий точный решатель задачи Римана работает только с двумя входными состояниями и эти граничные условия не применяет.

`output.destination` управляет диагностическим выводом: `console` — стандартный вывод, `file` — файл `output.file`. Ошибки конфигурации всегда пишутся в стандартный поток ошибок. Каталог для файла создаётся автоматически. Это именно текстовый диагностический вывод; числовые файлы для графиков относятся к следующим пунктам задания.

Парсер поддерживает понятное подмножество YAML: вложенные отображения, отступы по два пробела, скалярные значения и комментарии после `#`. Списки, ссылки, многострочные строки и кавычки не поддерживаются. Все ключи из примера обязательны; неизвестные ключи отклоняются, чтобы опечатка не оставалась незамеченной.

## Все поля и допустимые значения

**Общее правило для чисел:** записывайте десятичную точку, например `0.125`. Допустима экспоненциальная запись вроде `1e-3`. Парсер отклоняет `nan`, `inf` и значения, которые не являются конечными числами.

### `gas` и `method`

| Поле | Допустимые значения | Значение и использование |
| --- | --- | --- |
| `gas.gamma` | Любое конечное число строго больше `1`; в задании `1.4`. | Показатель адиабаты совершенного газа. По §15.2 из него вычисляются скорость звука `a = sqrt(gamma * p / rho)` и внутренняя энергия `e = p / ((gamma - 1) * rho)`. |
| `method.solver` | Сейчас только `exact`. | Выбор точного решателя Римана. Другие имена, включая `hll`, пока вызывают ошибку. |
| `method.scheme` | Сейчас только `none`. | Схема на сетке не запускается. `godunov` пока недоступен: часть 1 задания требует только решатель. |

Текстовые значения чувствительны к регистру: `Exact` не равно `exact`. Поля `method` предусмотрены для расширения комплекса по части 2 задания.

### `domain` — координаты задачи

| Поле | Допустимые значения | Значение и использование |
| --- | --- | --- |
| `domain.x_min` | Любое конечное число меньше `discontinuity`. | Левая граница области. |
| `domain.x_max` | Любое конечное число больше `discontinuity`. | Правая граница области. |
| `domain.discontinuity` | Конечное число строго между `x_min` и `x_max`. | Координата исходного разрыва `x0`. |

Область может отличаться от `[0, 1]`. Например, `x_min: -2`, `x_max: 2`, `discontinuity: 0` — допустимый набор. Координаты не влияют на давление и скорость между волнами: они нужны для проверки `sample_x` и вычисления луча `S = (sample_x - discontinuity) / sample_time` (§15.9).

### `initial` — начальные условия

Одинаковые правила действуют для `initial.left` и `initial.right`. Слева от `domain.discontinuity` задано состояние `initial.left`, справа — `initial.right`. Ровно на начальном разрыве значение не требуется.

| Поле с каждой стороны | Допустимые значения | Что означает |
| --- | --- | --- |
| `rho` | Любое конечное число строго больше `0`. | Плотность газа. |
| `u` | Любое конечное число: отрицательное, ноль или положительное. | Скорость вдоль оси `x`. Отрицательное значение означает движение влево. |
| `p` | Любое конечное число строго больше `0`. | Давление газа. |

Все три поля обязательны для обеих сторон. Например, `u: -2` слева и `u: 2` справа задают разлёт газов. Если разлёт создаёт вакуум по условию (15.15), программа сообщает об этом до итераций Ньютона. Нулевые или отрицательные начальные плотность и давление не принимаются.

### `boundary` — граничные условия для будущей схемы

`boundary.left` и `boundary.right` задаются независимо. Точный решатель *одного* разрыва пока не применяет эти условия: сетки и фиктивных ячеек в части 1 нет. Поля уже читаются и проверяются, чтобы конфигурация подходила для будущего расчёта.

| Поле | Допустимые значения | Значение |
| --- | --- | --- |
| `boundary.left.type`, `boundary.right.type` | `transmissive` или `fixed`. | Тип условия на соответствующей границе. |
| `boundary.<side>.rho` | При `type: fixed` обязательно конечное число `> 0`. | Плотность фиксированного состояния. |
| `boundary.<side>.u` | При `type: fixed` обязательно любое конечное число. | Скорость фиксированного состояния. |
| `boundary.<side>.p` | При `type: fixed` обязательно конечное число `> 0`. | Давление фиксированного состояния. |

`transmissive` означает, что в будущей схеме состояние в фиктивной ячейке будет копироваться из ближайшей внутренней ячейки. При этом `rho`, `u` и `p` не нужны. При `fixed` все три значения обязательны:

```yaml
boundary:
  left:
    type: fixed
    rho: 1.0
    u: 0.0
    p: 1.0
  right:
    type: transmissive
```

Если при `transmissive` всё же записать `rho`, `u` или `p`, парсер их примет, но не проверит и не использует. Лучше удалить их, чтобы файл не вводил в заблуждение.

### `output` — вывод и точка отбора

| Поле | Допустимые значения | Значение и использование |
| --- | --- | --- |
| `output.destination` | `console` или `file`, строчными буквами. | Куда выводить диагностические строки с результатом. |
| `output.file` | Любая непустая строка пути без кавычек и символа `#`. Обязательна даже при `destination: console`. | Путь к файлу при `destination: file`. |
| `output.sample_x` | Любое конечное число в замкнутом интервале от `x_min` до `x_max`. | Координата, в которой показывается состояние решения. |
| `output.sample_time` | Любое конечное число строго больше `0`. | Момент времени для отбора состояния. |

При `destination: console` строки идут в терминал. При `destination: file` программа создаёт родительский каталог и **перезаписывает** указанный файл. Относительный путь вроде `output/run.log` считается от текущего рабочего каталога. Ошибки всегда идут в стандартный поток ошибок и видны в терминале. Это текстовый диагностический вывод; файлы профилей для графиков пока не создаются.

Для выбранной точки вычисляется `S = (sample_x - discontinuity) / sample_time`. Если `sample_x` равно `discontinuity`, получится `S = 0`. Поток через неподвижную грань вычисляется при `S = 0` независимо от `sample_x` и `sample_time`. Например, в задаче Сода `sample_x: 0.4` и `sample_time: 0.2` дают `S = -0.5` — точку внутри левого веера разрежения.

## Правила записи файла

Парсер поддерживает **подмножество YAML**: вложенные блоки вида `ключ: значение`, ровно два пробела на уровень вложенности, пустые строки и комментарии после `#`. Списки, YAML-ссылки, кавычки, многострочные значения и табуляция не поддерживаются. Имена полей и текстовые значения чувствительны к регистру.

Все поля из `config.yaml` обязательны, кроме `rho`, `u` и `p` на границе с `type: transmissive`. Неизвестный или повторный ключ вызывает ошибку. При неверном значении программа выводит строку с префиксом `Error:` в терминал и возвращает код `1`. Обнаруженный физический вакуум — корректный исход для допустимых начальных данных: программа сообщает о нём и возвращает код `0`.
