# §1.1. Постановка и `config.yaml`

Программа читает один файл конфигурации. По умолчанию это `config.yaml` в текущем каталоге; другой путь можно передать первым аргументом: `./build/prac15 my_case.yaml`.

В `initial.left` и `initial.right` задаются постоянные начальные состояния слева и справа от `domain.discontinuity`: `rho` — плотность, `u` — скорость, `p` — давление. По §15.2 скорость звука равна `sqrt(gamma * p / rho)`, удельная внутренняя энергия — `p / ((gamma - 1) * rho)`. `gas.gamma` — показатель адиабаты. Плотность и давление должны быть положительными, `gamma` — больше единицы.

`domain.x_min` и `domain.x_max` задают отрезок для будущего отбора и графиков. `domain.discontinuity` — положение исходного разрыва внутри него. Для отбора в `output.sample_x` в момент `output.sample_time` используется луч `S = (sample_x - discontinuity) / sample_time` (§15.9). В схеме Годунова для неподвижной грани нужен `S = 0`.

`method.solver: exact` выбирает точный решатель. `method.scheme: none` показывает, что в части 1 схема на сетке не запускается. Другие имена пока отклоняются с сообщением об ошибке; в будущем здесь можно будет выбрать HLL, HLLC или схему Годунова без изменения точного решателя.

`boundary.left` и `boundary.right` — граничные условия будущего расчёта на сетке. Тип `transmissive` означает копирование внутреннего состояния в фиктивную ячейку; тип `fixed` означает заданные `rho`, `u`, `p` в блоке соответствующей границы. Текущий точный решатель задачи Римана работает только с двумя входными состояниями и эти граничные условия не применяет.

`output.destination` управляет диагностическим выводом: `console` — стандартный вывод, `file` — файл `output.file`. Ошибки конфигурации всегда пишутся в стандартный поток ошибок. Каталог для файла создаётся автоматически. Это именно текстовый диагностический вывод; числовые файлы для графиков относятся к следующим пунктам задания.

Парсер поддерживает понятное подмножество YAML: вложенные отображения, отступы по два пробела, скалярные значения и комментарии после `#`. Списки, ссылки, многострочные строки и кавычки не поддерживаются. Все ключи из примера обязательны; неизвестные ключи отклоняются, чтобы опечатка не оставалась незамеченной.
