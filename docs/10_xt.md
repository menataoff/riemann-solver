# §1.4.2. Диаграммы x–t с полем плотности

Для каждого теста `export_toro` записывает `xt_density.csv`: 401 точку по `x` и 201 момент по `t` от `0` до `t_out`, всего 80601 строка данных. При `t = 0` берутся исходные постоянные состояния слева и справа от `x0`. При `t > 0` плотность берётся из точного решения задачи Римана по лучу `S = (x - x0) / t` (§15.9). C++ код только записывает данные, а `scripts/plot_xt.py` читает CSV и строит график.

## Как построить

Из корня проекта выполните:

```bash
./build/export_toro
.venv/bin/python scripts/plot_xt.py
```

Получатся `docs/figures/toro_N_xt.png` для `N = 1…5`. Цвет фона показывает плотность. Ударные волны нанесены сплошными линиями `x = x0 + S_shock*t`. Контактный разрыв — белой штриховой линией `x = x0 + u_star*t`. Для каждой волны разрежения отдельно нанесены голова, хвост и **пять промежуточных лучей**. Скорости волн получены в §15.9 и записаны в `metadata.csv` вместе с параметрами задачи.

Подписи `W_L`, `W_*L`, `W_*R`, `W_R` обозначают четыре постоянные области на схеме распада разрыва из §15.4. Между головой и хвостом разрежения лежит непрерывный веер; он не является областью постоянных параметров. В тесте 2 слева и справа от контакта состояния совпадают, поэтому белая линия контакта не сопровождается скачком плотности.
