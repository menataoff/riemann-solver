# §1.2.1. Давление между волнами

`solve_pressure(left, right, gamma)` из `pressure_solver.hpp` возвращает `PressureResult`: давление `pressure`, выбранное начальное приближение `initial_pressure`, его тип `guess_method` и число итераций `iterations`. Никаких файлов функция не открывает и ничего не печатает. Код функции волны `f(p, W)` и её производной вынесен в `wave_function.hpp`.

По формулам (15.10)–(15.13) решается `f_L(p) + f_R(p) + u_R - u_L = 0`. Ветвь `f` выбирается сравнением текущего давления с начальным давлением на соответствующей стороне: выше — ударная волна, ниже — разрежение.

Начальное приближение выбирается по правилу GUESSP из §15.8: `acoustic` — формула (15.18) при близких давлениях и допустимом результате; `two_rarefactions` — (15.19), если линейная оценка меньше обоих давлений; `two_shocks` — (15.20) в остальных случаях. После этого выполняются шаги Ньютона (15.16) с производными (15.17).

Остановка — относительное изменение давления меньше `1e-6`; число итераций выводит `main.cpp`. Если шаг Ньютона даёт отрицательное давление, оно заменяется на `1e-12`, как разрешено в §15.7. За 100 итераций без сходимости выдаётся ошибка. Проверка вакуума будет добавлена в пункте 1.2.6.

Сборка: `cmake -S . -B build && cmake --build build`. Запуск: `./build/prac15 config.yaml`. Куда пишется строка с давлением, задаёт `output.destination` в `config.yaml`.
