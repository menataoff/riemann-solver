# §1.2.4. Отбор состояния по лучу

`sample_solution(S, left, right, gamma, star, waves)` из `sample_solution.hpp` возвращает `PrimitiveState` на луче `S = (x - x0) / t` (§15.9). Функция не знает координаты `x`, времени `t`, сетки или файлов. Сначала сравнивает `S` со скоростью контактного разрыва `u_star`; затем выбирает исходное состояние, состояние за волной или формулы внутри веера разрежения (15.22) и правый аналог из §15.9.

Для точки ровно на контактном разрыве `S == u_star` выбирается левое состояние. На самом разрыве два предельных значения плотности, так что для будущих графиков этот выбор нужно учитывать.

Чтобы запросить точку через конфигурацию, измените `output.sample_x` и `output.sample_time` в `config.yaml`. Например, в задаче Сода `sample_x: 0.4`, `sample_time: 0.2` даёт `S = -0.5` и точку внутри левого веера. Запуск: `./build/prac15 config.yaml`.
