# §1.4.1. Профили шести величин

Для каждого из пяти тестов `export_toro` решает задачу Римана из соответствующего YAML-файла и записывает `output/cases/toro_N/profile.csv`. В файле **1001 точка** на отрезке `[x_min, x_max]`, включая концы. Столбцы: координата `x`, плотность `rho`, скорость `u`, давление `p`, удельная внутренняя энергия `e`, скорость звука `a` и энтропийная функция `s = p / rho^gamma`. Значения `rho`, `u`, `p` берутся через отдельную функцию отбора `sample_solution` при `S = (x - x0) / t_out` (§15.9); остальные три величины вычисляются по формулам §15.2 и определению `s` из задания. Расчётная программа графики не строит.

`metadata.csv` рядом с профилем содержит исходные параметры и скорости волн. Отдельная программа `scripts/plot_profiles.py` читает оба CSV-файла и строит для каждого теста рисунок с шестью панелями. Ударная волна показана сплошной вертикальной линией, голова и хвост веера разрежения — пунктирными, контактный разрыв — чёрной штриховой. Координаты линий равны `x0 + speed * t_out`.

## Воспроизведение

Из корня проекта, после сборки C++ кода и установки Python-зависимостей:

```bash
./build/export_toro
.venv/bin/python scripts/plot_profiles.py
```

Вторая команда сохраняет пять PNG в `docs/figures/`. Зависимости постобработки перечислены в `requirements.txt`; установка: `.venv/bin/pip install -r requirements.txt`. Исходные CSV лежат в `output/cases/` и могут быть восстановлены первой командой.

## Что видно на графиках

- На контактном разрыве давление и скорость непрерывны (§15.4). Плотность может прыгать; тогда из-за зависимости от `rho` скачут также `e`, `a` и `s`. В тесте 2 состояния по обе стороны контакта одинаковы, поэтому сам контакт на профилях не виден.
- На ударной волне меняются `rho`, `u`, `p`; вслед за ними меняются `e`, `a`, `s`. В задаче Сода ударная волна справа, в тесте 4 — слева, в тесте 5 — с обеих сторон.
- Волна разрежения является непрерывным веером: внутри него `rho`, `u`, `p`, `e`, `a` меняются плавно. Энтропийная функция `s` внутри каждой такой волны постоянна, поскольку соотношение плотности и давления в §15.5 изэнтропическое. В тесте 2 веера два, в тестах 1 и 3 — слева, в тесте 4 — справа.
- В тестах 3–5 масштабы давления и скорости велики; каждый рисунок строится со своим масштабом осей, а не с общим масштабом всех тестов.
