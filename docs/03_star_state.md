# §1.2.2. Скорость и плотности около контакта

`calculate_star_state(left, right, gamma, pressure)` из `star_state.hpp` принимает положительное `p_star` и возвращает `StarState` с `p`, `u`, `rho_left`, `rho_right`. Скорость вычисляется по полусумме (15.14). Для плотности на каждой стороне выбирается ударная формула из §15.5 при `p_star > p_K`, иначе изэнтропическая формула разрежения (15.11).

На контактном разрыве `p` и `u` одинаковы с обеих сторон, а плотности могут различаться (§15.4). Функция не читает конфигурацию и не пишет вывод. После сборки `./build/prac15 config.yaml` показывает четыре величины; место вывода задаёт `output.destination`.
