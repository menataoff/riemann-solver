# §1.2.5. Поток через неподвижную грань

`calculate_face_flux(left, right, gamma, star, waves)` из `face_flux.hpp` сначала вызывает отбор решения при `S = 0`, затем вычисляет поток (15.23). Возвращаемый `FaceResult` содержит само состояние `state` и три компоненты `flux`: массу `rho*u`, импульс `rho*u*u + p`, энергию `(rho*E + p)*u`, где `rho*E = p/(gamma - 1) + rho*u*u/2` по §15.2.

Грань считается неподвижной. Функция не зависит от сетки или `config.yaml`; схема Годунова в будущем сможет вызывать её для любых соседних состояний. Запуск примера: `./build/prac15 config.yaml`. Строки `face at S=0` и `flux` идут в консоль или файл по `output.destination`.
